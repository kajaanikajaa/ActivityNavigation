# Activity Navigation App

## 📱 Project Description

This is a simple Android application developed using Android Studio and Kotlin. It demonstrates navigation between two activities.

## ✨ Features

* Displays a welcome screen in the MainActivity.
* Provides a button to navigate to the SecondActivity.
* Demonstrates basic Android activity navigation.

## 🛠️ Technologies Used

* Android Studio
* Kotlin
* Jetpack Compose

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle Sync to complete.
4. Select an Android emulator or connect an Android device.
5. Click the **Run** button to launch the application.

## 📌 Application Flow

1. Open the application.
2. The MainActivity displays the welcome screen.
3. Click the **Second Activity** button.
4. The application navigates to the SecondActivity.
